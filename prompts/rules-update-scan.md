# Rule and field update scan

Search public sources for updates to the competition rules, field dimensions, or schedule that affect this robot. Compare what you find against the recorded rules baseline in the input file.

Report:

1. any public page or post that changes a rule, field dimension, or date;
2. the URL for each finding;
3. whether the finding contradicts the recorded baseline;
4. which measurement or decision would be affected.

In live mode the harness sends the recorded query to the search provider and stores the formatted results as the evidence body; this template records the intent and the review questions.

This output is agent-run and advisory. Do not claim owner review, physical testing, or competition qualification.
