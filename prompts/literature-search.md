# Literature search

Find citable references for the topics recorded in the input file: small mobile robot obstacle avoidance, path planning, differential drive odometry, and similar competition-relevant robotics.

Report:

1. title, authors or venue, year, and identifier (DOI or venue id) for each work;
2. one sentence on why it is relevant;
3. links that a reviewer can check.

Rules:

- Only report works returned by the search provider. Do not invent titles or identifiers.
- Prefer works with resolvable identifiers.

In live mode the harness sends the recorded query to the scholarly search provider and stores the formatted results as the evidence body; this template records the intent and the review questions.
