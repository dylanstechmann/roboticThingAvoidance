# Web page read

Read the vendor product page recorded as this task's query and extract the engineering facts: motor body dimensions, shaft size, gear ratio, voltage and current ratings, mass, and any linked dimension drawing or CAD file.

Report:

1. the page URL and the key specification table;
2. any stated tolerances;
3. links to dimension drawings or CAD downloads found on the page.

Rules:

- Only report values present on the page. Do not fill gaps from memory.
- Note explicitly when a value is missing from the page.

In live mode the harness fetches the page through the page-read provider and stores the returned markdown as the evidence body; this template records the intent and the review questions.

## Advisory boundary

This output is agent-run and advisory. Do not claim owner review, physical testing, or competition qualification.
